# Appendix F: Prompt Lineage

The input of the model has three layers, which are kept apart throughout this thesis.
The *system prompt* is the strategy text; it is the only layer that the prompt optimiser changes and the only one called a prompt version.
The *static floor map*, generated by the engine, is appended once to the system prompt at the start of an episode.
The *per-turn observation*, also generated by the engine, is the user message of each call (Section 5.2).
The second and third layers are identical for every prompt version; a change to them is a change of the observation, not of the prompt.

Table F.1 lists the system prompts of the conditions reported in Chapter 6 with their role; the earlier hand-written prompt of Table 6.5, row 1, is stored in the run logs of that row.
Prompts with a listing number are reproduced in Appendix A.
The other evolved prompts are stored in the repository and in the result files of Appendix D.
