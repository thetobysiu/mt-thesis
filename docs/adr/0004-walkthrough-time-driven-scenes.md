# Walkthrough as time-driven scenes, rendered to video from the page

The three-minute walkthrough is a React timeline in which every frame is a pure function of the time t, drawn on a fixed 1280 × 720 canvas scaled with CSS zoom; the video file is produced by stepping that same page frame by frame in a headless browser and encoding the screenshots with ffmpeg, and the music is generated with WebAudio from a fixed chord sequence and rendered offline for the file. A motion-graphics tool (Manim, a Mografy-style editor) was not used because it would redraw the maps, numbers and annotations from a second copy of the data, while the timeline reuses the site's own map tiles, engine and stored results, lets a viewer pause and open the live demo at the same point, and keeps the interactive version and the video identical; the cost is that the video must be re-rendered locally (`npm run capture`, Playwright and ffmpeg installed without saving) after a scene changes, since CI has neither tool.
