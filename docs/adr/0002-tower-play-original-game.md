# Tower play uses the original game, not the thesis engine

The Play page embeds the original 24-floor HTML5 game (mota-js), while every tower run in the thesis was played on the thesis engine, which models the game's scripted events only partly (Table B.4). Porting the tower engine to TypeScript would add a second engine to verify; we accept that a visitor's game is not the experimental condition and say so on the page, and stored tower runs are shown as replays of the thesis engine.
